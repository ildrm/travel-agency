Atlas Leisure block theme — development preview

A presentation-only WordPress block theme with optional WooCommerce and Atlas companion services. Installation does not install companion plugins, import demo offers, enable payments or create fictional inventory. Site name, menus, global styles and templates are editable via the Site Editor. On the front page, ?lang=en or ?lang=fa selects the interface language; the language switch preserves the current URL. Public offer detail uses ?offer_id=<id>; the companion must authorize/filter all data.

The theme uses atlas_catalog, atlas_offer, atlas_account and atlas_portal when provided by a companion. In their absence it renders a localized unavailable message. A theme change does not remove companion data. WooCommerce itself controls product and checkout behavior; a tested gateway is a separate dependency. No provider compatibility or legal approval is implied.

The artwork in assets/svg is original code-authored vector geometry for this repository; brand, cultural and similarity clearance are outstanding. 3D is not required for the core experience. Compatibility, clean installation, WCAG, native Persian, Woo checkout, performance and provider flows require real integration testing. WordPress and WooCommerce versions require evidence-based release validation.
