## Quality/release boundaries

NFR-SEC/PRIV require independent security/privacy review and approved retention; local negative tests are supporting evidence, not certification. NFR-A11Y/LOC require native and assistive-technology review beyond automated axe and screenshots. NFR-PERF has local navigation samples only, never field p75 or load-capacity claims. NFR-REL requires production-like scheduler/monitoring/provider reconciliation in addition to the isolated restore drill. NFR-MAINT is limited to actually tested versions/archives; the authored CI workflow has not run on GitHub. NFR-CONC includes two-connection real DB races; 100 concurrent PHP workers/peak-load testing is intentionally not run on this active workstation.

The current build can be reviewed and exercised locally. It must not be represented as complete against the entire implementation prompt, production-approved, or ready for every later-phase business operation. STATUS.md and TEST-EVIDENCE.md record the latest executed checkpoint.
